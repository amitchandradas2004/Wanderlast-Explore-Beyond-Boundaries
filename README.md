# 🌍 Wanderlust

A modern full-stack travel booking web application built with **Next.js**, designed to explore destinations, manage bookings, and deliver a smooth user experience.

---

## Live Link: [Click Here](https://wanderlust-five-green.vercel.app/)

---

## ✨ Features

- 🔎 Browse travel destinations
- 📄 Detailed destination pages
- 🧳 Book and manage trips
- 🔐 Authentication system (secure user sessions)
- 🗂️ Admin-friendly structure for managing data
- ⚡ Fast, responsive, and SEO-optimized UI
- 📱 Fully mobile responsive design
- 🔔 Toast notifications for user actions

---

## 🛠️ Tech Stack

**Frontend**

- Next.js (App Router)
- React
- JavaScript
- HeroUI
- DaisyUI
- Tailwind CSS

**Backend**

- Node.js
- Express.js
- MongoDB

**Authentication**

- BetterAuth
